# 部署说明

## 前置条件

- GitHub 账号（项目已推送到仓库）
- Netlify 账号（netlify.com 免费注册）
- Supabase 项目已创建（Task 1 已完成，拿到 URL 和 Service Key）
- 智谱 API Key（open.bigmodel.cn 获取，免费）

## 部署步骤

### 1. 推送代码到 GitHub

```bash
git remote add origin https://github.com/你的用户名/tuiwen.git
git push -u origin master
```

### 2. Netlify 导入站点

1. 登录 [app.netlify.com](https://app.netlify.com)
2. 点 **Add new site → Import an existing project from Git**
3. 选 GitHub → 授权 → 选 `tuiwen` 仓库
4. 构建配置**无需手动填**，netlify.toml 已预设：
   - Build command: `cd frontend && npm install && npm run build`
   - Publish directory: `frontend/dist`
   - Functions directory: `backend/functions`
5. 点 **Deploy site**

### 3. 配置环境变量

部署完成后，进入 **Site configuration → Environment variables**，添加以下 5 个变量：

| 变量名 | 值 | 说明 |
|--------|-----|------|
| `ACCESS_CODE` | `你的口令` | 进入系统的口令（前端 X-Access-Code） |
| `SUPABASE_URL` | `https://xxx.supabase.co` | Supabase 项目 URL |
| `SUPABASE_SERVICE_KEY` | `sb_secret_xxx` | Supabase service role key（非 anon） |
| `ZHIPU_API_KEY` | `你的智谱Key` | AI 生成调用凭证 |
| `ZHIPU_MODEL` | `glm-4-flash-250414` | 模型名（可选，默认 glm-4-flash；4.7-flash 高峰期限流频繁，不推荐） |

**注意**：配置完后需触发一次重新部署（Deploys → Trigger deploy → Deploy site）使环境变量生效。

### 4. 验证上线

打开 Netlify 分配的域名（如 `https://tuiwen-xxx.netlify.app`）：

1. 输入口令进入
2. 新建任务 → 进入详情
3. 点「AI 初稿」确认 AI 调用正常
4. 点「规范检查」确认门禁工作
5. 点「复制到秀米」确认导出正常

## 常见问题

### Q: 部署后 API 报 401？

口令环境变量 `ACCESS_CODE` 未配置或值与前端请求头不一致。检查 Netlify 环境变量，重新部署。

### Q: AI 功能报 429？

智谱免费模型高峰期限流。等几分钟重试，或在环境变量把 `ZHIPU_MODEL` 换成 `glm-4-flash-250414`。

### Q: 函数报 500？

检查 Netlify → Functions 日志（Site → Functions → 对应函数 → Logs）。最常见原因是 Supabase 环境变量拼写错误。

### Q: 前端能打开但接口 404？

`netlify.toml` 的 redirects 规则把 `/api/*` 转发到 `/.netlify/functions/*`，已预配。如仍 404，确认 `backend/functions/` 下有 `tasks.mjs`、`ai.mjs`、`check.mjs` 三个文件。

### Q: 数据库表没建好？

在 Supabase → SQL Editor 执行项目根的 `supabase-schema.sql`（建 tasks、rules 表）。

## 本地开发

```bash
# 安装依赖
cd frontend && npm install
cd ../backend/functions && npm install

# 启动本地服务（后端 8888 + 前端 5173）
cd ../..
node dev-server.mjs   # 后端
cd frontend && npm run dev   # 前端（新终端）
```

环境变量放在 `.env.local`（已被 gitignore，不会提交）。
